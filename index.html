MC Translator ↗ mc-zh-tw-translator

把 Minecraft 模組包（模組、任務、Patchouli 書本、KubeJS、設定檔）翻成台灣用語繁體中文的桌面工具，Python 開發、發佈為 Windows 免安裝 exe。

譯文來源分 10 層依序查找：模組原本附的繁中 → 同模組附的簡中 → 模組包裡的中文 → 參考庫（ModsTranslationPack → CFPA → ParaTranslationPack）→ 跨版本 CFPA → 翻譯記憶 → 自訂譯名 → 官方原版譯名 → 內建術語表 → 最後才選用 AI 補翻；簡中以 OpenCC 轉台灣用語。自動排除遊戲不會顯示的文字；逐筆檢查參數、格式碼、換行一致才採用；套用前自動備份原檔、可還原；譯名不一致偵測與推薦。

A desktop tool that translates Minecraft modpacks (mods, quests, Patchouli books, KubeJS, config files) into Traditional Chinese with Taiwanese terminology; written in Python and shipped as a portable Windows exe.

Translations are resolved through a 10-tier source chain: the mod’s own zh-TW → the same mod’s zh-CN → Chinese already inside the modpack → reference libraries (ModsTranslationPack → CFPA → ParaTranslationPack) → cross-version CFPA → translation memory → custom glossary → official vanilla names → built-in terminology → optional AI fill-in as the last resort; Simplified Chinese is converted to Taiwanese usage via OpenCC. Skips text the game never displays; accepts each entry only if placeholders, format codes, and line breaks match; backs up originals before applying and can restore them; detects inconsistent term translations and recommends fixes.
